# Thesis Project Structure

This repository is organized for a typical master's thesis workflow.

## Main structure

- `thesis/` — manuscript and chapter content
  - `chapters/` — numbered chapter folders
  - `appendix/` — appendix files
  - `figures/` — generated or source figures for the thesis
  - `references/` — bibliography and citation-related files
- `code/` — all implementation code
  - `src/` — production code
  - `scripts/` — analysis or utility scripts
  - `notebooks/` — exploratory notebooks
- `data/` — datasets and processed files
  - `raw/` — original data
  - `processed/` — cleaned and prepared data
- `results/` — experiment outputs
  - `plots/` — charts and visualizations
  - `metrics/` — tables and evaluation summaries
- `docs/` — project notes and documentation
  - `notes/` — meeting notes, ideas, and planning

## Suggested usage

- Put the written thesis content under `thesis/chapters/`.
- Store code in `code/` and data in `data/`.
- Save plots, tables, and evaluation artifacts in `results/`.
- Keep documentation and notes in `docs/`.
