# Manuscript

Chapters live in `chapters/<NN_name>/`. Each chapter folder holds its own
source file(s) — keep one file per chapter unless a chapter gets long enough to
split by section.

A figure enters `figures/` only when it is actually cited in the text; it is
copied there from `results/plots/` so the manuscript stays reproducible from a
fixed set of images.

Writing: team members draft the text themselves — AI is used for polishing at
the end only (CLAUDE.md).
